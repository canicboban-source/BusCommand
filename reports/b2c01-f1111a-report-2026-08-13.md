## Real focus / event problem

Unloaded Escape was bound only as `keydown` on `#sa-create-company-modal` (`data-sa-shell-escape-bound="1"`).  
After cold Open + chunk failure, the flow module never loaded and never moved focus into the dialog. Focus could remain on the external `#sa-open-create-modal` button, so Escape never reached the modal listener → shell stayed open.

### Fail-first (red)

`C:\Users\cane\Desktop\BusCommand-ca-monthly-import\reports\b2c01-f1111a-logs\01-fail-first-escape.txt`  
EXIT=1 — after loader-failure toast, `page.keyboard.press("Escape")` left `#sa-create-company-modal` **visible**.

### Fix

1. **Sync focus** into `#sa-new-name` (safe in-modal control) immediately on shell open, before `await`/import.  
2. **Document-level capture Escape guard** while unloaded; removed on local dismiss and on successful module load so the flow module is the sole Escape owner afterward (partial/unknown → leave-confirm unchanged).
