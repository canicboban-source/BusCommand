Tenant-scoped, server-only (Rules already deny client `ops/*`):

```
companies/{companyId}/ops/company_admin_slot
  {
    uid: string,          // winning Auth uid
    claimedAt: timestamp
  }
```

Transaction (after Auth create+claims):

1. `get(companyRef)` exists  
2. `get(settings/main)` operable (not suspended)  
3. `get(slotRef)` — if exists → `CA_EXISTS`  
4. optional: query any `company_admin` (active|inactive) → `CA_EXISTS`  
5. `set(users/{uid})` + `set(slotRef)` + success audit  

Parallel losers: tx retry sees slot → abort → **Auth.deleteUser**.
