# Faza 3 — UI/UX, Responsive, Accessibility i vizuelni polish (2026-08-08)

## Cilj

Primeniti smernice Master Prompt Poglavlja 27–35 na operativne UI korekcije: Driver bottom nav, uklanjanje Trial/Demo chrome-a, Dispo Attention amber CTA, bezbedniji row actions, responsive matrica 360–1920.

## Početno stanje

- Driver nav HTML redosled već bio Plan · Smene · SOS · Prijavi · Poruke, ali CSS nije držao SOS kao fiksiran centar.
- Header prikazivao Trial chip (`Probni period · N dana`) i PREVIEW badge.
- CA Groups/Team imali direktna Delete/Deactivate dugmad u redu.
- Attention panel postojao; deo Apply dugmadi bio `btn-secondary` umesto amber `urgent-action`.
