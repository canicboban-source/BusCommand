### 2. Exact loader-toast lifecycle
- **ŠTA:** Dedicated ownership via `showSaCreateLoaderFailureToast` / `dismissSaCreateLoaderFailureToast` + `data-sa-create-loader-toast`. New loader failure replaces only the prior loader toast. Successful load clears loader toast. Execution catch stays `error_generic` (not loader-owned). `showToast` DOM-handle contract retained.
- **ZAŠTO:** Retry success left stale “module could not be loaded” toasts; global wipe would kill unrelated/outcome toasts.
- **DONOSI:** After failure = **1** loader toast; after retry = **0**; unrelated sentinel = **1**.

Pure `createSaCreateCompanyFlowLoader()` for unit tests. E2E proves production API with harness off + Firebase CDN route stub (no new production global).
