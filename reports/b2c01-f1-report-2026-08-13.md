## Root cause

1. Production CA follow-up required `#sa-create-admin-btn`; DOM only has `#sa-create-company-btn`.
2. `runSingleSubmission(null, …)` → `{ started: false }` → `createUser` never ran.

## What changed / why / what it delivers

**What**
- Lazy module `js/admin/sa-create-company-flow.js` orchestrates company → CA with whole-flow single-flight.
- Thin loaders in `js/admin/superadmin.js` (no phantom button).
- Partial-success banner + in-modal leave confirmation + i18n (sr/en/de) + minimal CSS.
- Unit + production-mode E2E + visual trail.

**Why**
- Stop leaving companies without CA while UI claims success.
- Allow truthful partial success and CA-only retry from confirmed session success.

**Delivers**
- Company created at most once per successful write in the session.
- CA uses **only** server-returned `companyId`.
- CA failure keeps modal open; retry is CA-only.
- Generic 409 / unknown timeout do **not** create CA.
- Password never stored in module memory / storage / reports / screenshots (masked input).
